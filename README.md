# Requirements
- Neovim >= **0.10.0** (select branch corresponding to your version)
    - Must be built from source (see [here](https://github.com/neovim/neovim/blob/master/BUILD.md))
- Git 
- a Nerd Font(**v3.0** or greater)
- Lazygit **(optionnal)**
- a **C** compiler for nvim-treesitter
- curl
- fzf
- ripgrep
- fd
- bat
- a terminal that support true color and *undercurl*
